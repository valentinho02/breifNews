# breifNews

군 복무 중 뉴스를 챙겨 보고 싶어서 약 1년 전에 만든 개인 프로젝트입니다. 바쁜 일과 때문에 밀린 뉴스를 모아 보고, 관심 있는 주제의 소식을 텔레그램으로 받아보기 위해 만들었습니다. AI의 도움을 받아 개발했습니다.

네이버 뉴스 검색 API로 관심 키워드의 뉴스를 20초마다 확인하고, 수집한 뉴스를 JSON 파일로 저장합니다. 새로 발견한 기사의 제목과 링크를 텔레그램으로 전송합니다.

## 사용법

1. Node.js와 npm을 설치한 뒤 의존성과 설정 파일을 준비합니다.

   ```sh
   cd server
   npm ci
   cp .env.example .env
   ```

2. `server/.env`에 값을 입력합니다.

   - `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`: 네이버 개발자센터에서 발급받은 검색 API 인증 정보
   - `PORT`: 서버 포트 (기본값 `3000`)
   - `TELEGRAM_BOT_TOKEN`: BotFather에서 발급받은 봇 토큰
   - `TELEGRAM_CHAT_IDS`: 뉴스를 받을 채팅 ID. 여러 개라면 쉼표로 구분합니다. 먼저 텔레그램에서 봇과 대화를 시작하세요.

   텔레그램 설정을 비워두면 뉴스 저장만 수행합니다.

3. `data/topics.json`에 관심 키워드를 설정합니다. `english`에는 파일명에 사용할 간단한 영문 이름을 넣습니다.

   ```json
   [
     { "korean": "삼성전자", "english": "samsung" }
   ]
   ```

4. `server` 폴더에서 실행합니다.

   ```sh
   npm start
   ```

서버가 실행되는 동안 주기적으로 수집하며, 결과는 `data/YYYY_MM_DD_주제_news.json`에 저장됩니다. 한국 날짜 기준으로 사용하려면 실행 환경의 시간대를 `Asia/Seoul`로 설정하세요. 종료는 `Ctrl+C`입니다.

## 참고

- 현재는 실행 당일 기준 뉴스 수집과 알림을 지원합니다. 과거 1년치 뉴스를 자동으로 복원하거나 요약하는 기능은 없습니다.
- 별도의 웹 화면은 포함되어 있지 않습니다. 관심 주제는 `topics.json`을 수정한 뒤 서버를 재시작하면 적용됩니다.
- `.env`, `node_modules`, 수집된 뉴스 파일은 Git에 올리지 않습니다. 실제 키는 각자의 로컬 `.env`에 보관하세요.
